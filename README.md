A1.O Bootstrap é um framework front-end de código aberto criado pelo Twitter em 2011. Ele segue a abordagem mobile-first, ou seja, os estilos base são pensados para telas pequenas e você adiciona classes para telas maiores. É CSS puro + classes utilitárias, sem depender de JavaScript para a maioria dos estilos. O JS do Bootstrap só é necessário para componentes interativos.

A2.Se inclui via CDN (Content Delivery Network), com uma única tag <link> no <head>, antes do arquivo css de estilo próprio:
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />

A3. - Redução do tamanho do código css, o deixando mais enxuto.
    - Adição de Responsividade aos ícones.
    - Consistência Visual do framework.

A4. - Aparência Genérica.
    - Dificuldade de personalizar e sobrescrever elementos bootstrap com css padrão.

A5.  Somente Classes, pois garante a capacidade de combinar várias classes em um mesmo elemento html e sobrescrever o bootstrap com elementos css puros. Ambas possibilidades inviáveis utilizando IDs.
